Part I — CSS Foundations

Chapter 1: How CSS Works

1.1 What Is CSS?

Cascading Style Sheets (CSS) is the language that controls how HTML elements look on screen. HTML provides structure; CSS provides presentation — colors, spacing, layout, typography, and animation.

CSS is applied to HTML in three ways:

  • Inline — a style attribute on a single element.
  • Internal — a <style> block inside <head>.
  • External — a separate .css file linked with <link> (preferred).

1.2 CSS Rule Anatomy

Every CSS rule has a selector and a declaration block:

selector {
  property: value;
  property: value;
}

The selector targets HTML elements; each declaration sets one visual property.

1.3 The Cascade & Specificity

When multiple rules target the same element, CSS resolves conflicts using three factors (in order):

  1. Origin & importance — user-agent styles < author styles < !important.
  2. Specificity — inline styles > IDs > classes/attributes/pseudo-classes > type selectors.
  3. Source order — later rules win over earlier ones at equal specificity.
Specificity Scoring

style="…" (inline)Wins over all non-!important

1.4 Inheritance

Some properties (mostly text-related) are inherited by child elements automatically: color, font-family, font-size, line-height, text-align, etc.

Layout properties like margin, padding, border, display, width, and height are not inherited.

You can force inheritance with the inherit keyword or reset with initial / unset.

Chapter 2: CSS Selectors — Comprehensive Guide

2.1 Simple Selectors

Type (Element) Selector

Targets every instance of an HTML element.

p  { color: #333; }
h1 { font-size: 2rem; }
Class Selector

Targets elements with a specific class attribute. Prefixed with a dot.

.card    { border: 1px solid #ccc; }
.active  { background: #0af; }
ID Selector

Targets the single element with a matching id. Prefixed with #. Use sparingly — IDs have high specificity.

#header { position: sticky; top: 0; }
Universal Selector

* matches every element. Often used in resets.

*, *::before, *::after {
  box-sizing: border-box;
}

2.2 Grouping Selector

Comma-separate selectors to apply the same styles to multiple targets.

h1, h2, h3 {
  font-family: Georgia, serif;
  color: #222;
}

2.3 Combinator Selectors

Descendant (A B)

Matches B anywhere inside A.

nav a { text-decoration: none; }
Child (A > B)

Matches B only when it is a direct child of A.

ul > li { list-style: square; }
Adjacent Sibling (A + B)

Matches B when it immediately follows A.

h2 + p { margin-top: 0; }
General Sibling (A ~ B)

Matches all B elements that follow A (same parent).

h2 ~ p { color: #555; }

Chapter 3: The Box Model

3.1 Content, Padding, Border, Margin

Every element is a rectangular box with four layers:

  1. Content — the text / child elements.
  2. Padding — space between content and border.
  3. Border — the visible edge.
  4. Margin — space outside the border (between this box and neighbors).

3.2 box-sizing

By default (content-box), width sets only the content width — padding and border are added on top.

With border-box, width includes padding and border. This is almost always what you want:

*, *::before, *::after {
  box-sizing: border-box;
}

3.4 Margin Collapse

Vertical margins of adjacent block elements collapse — the larger margin wins, they don't add together. This only happens with block layout; flexbox eliminates margin collapse between flex items, which is one reason it's easier to work with.

Part II — Flexbox Core

Chapter 4: Introducing Flexbox

4.1 What Is Flexbox?

The Flexible Box Layout Module (flexbox) is a one-dimensional layout system. It distributes space among items in a container and controls their alignment, even when their sizes are unknown or dynamic.

"One-dimensional" means flexbox handles layout in one direction at a time — either a row or a column (unlike CSS Grid, which is two-dimensional).

4.2 Flex Container vs Flex Items

Set display: flex on a parent element to make it a flex container. Its direct children automatically become flex items.

.container {
  display: flex;   /* This element is now a flex container */
}
/* All direct children of .container are flex items */

4.3 Axes: Main & Cross

Flexbox uses two axes:

  • Main axis — the direction items flow. Default: horizontal (left → right).
  • Cross axis — perpendicular to main. Default: vertical (top → bottom).

6.1 order

Controls the visual order of items. Default is 0. Lower values appear first.

.item-c { order: -1; }  /* moves before items with order: 0 */
.item-a { order: 2; }   /* moves after items with order: 0 or 1 */

Defines how much an item should grow relative to siblings when extra space is available. Default is 0 (don't grow).

6.3 flex-shrink

Defines how much an item shrinks when the container is too small. Default is 1. Set to 0 to prevent shrinking.

.no-shrink { flex-shrink: 0; }  /* this item won't shrink */
.shrinks   { flex-shrink: 3; }  /* shrinks 3× faster than default */

6.4 flex-basis

Sets the initial size of an item before flex-grow / flex-shrink apply. Works like width (in row) or height (in column).

.item { flex-basis: 200px; }  /* start at 200px, then grow/shrink */
.item { flex-basis: 25%;   }  /* start at 25% of container */
.item { flex-basis: auto;  }  /* use the item's width/content (default) */

Chapter 8: Responsive Design with Flexbox

8.1 Media Queries Recap

Media queries apply CSS rules conditionally based on viewport size:

/* Mobile-first: base styles are for small screens */
.container { flex-direction: column; }

/* Tablet and up */
@media (min-width: 768px) {
  .container { flex-direction: row; }
}

/* Desktop */
@media (min-width: 1024px) {
  .container { gap: 32px; }
}

8.2 Responsive Patterns

Pattern 1: Column → Row

Stack items vertically on mobile, switch to horizontal on wider screens.

.stack-to-row {
  display: flex;
  flex-direction: column;
  gap: 16px;
}
@media (min-width: 600px) {
  .stack-to-row { flex-direction: row; }
}

8.3 Best Practices Summary

  1. Use flex shorthand — flex: 1 is clearer than setting grow/shrink/basis separately.
  2. Use gap over margins — no need to remove margins on first/last items.
  3. Let items wrap — flex-wrap: wrap with a flex-basis often removes the need for media queries.
  4. Don't overuse order — it changes visual order but not tab/screen-reader order (accessibility concern).
  5. Use min-width: 0 on flex items when text overflow / truncation is needed — flex items default to min-width: auto.
  6. Combine with Grid — use flexbox for one-dimensional flow, CSS Grid for two-dimensional layouts.
