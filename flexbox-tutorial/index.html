What is Flexbox?

Flexbox (Flexible Box Layout) is a CSS layout model that lets you arrange items in a row or column, distribute space between them, and align them — all with a few properties on the container.

You activate flexbox by adding display: flex to a parent element. That parent becomes the flex container. Its direct children become flex items. Toggle it below to see the difference.

Lesson 2 of 8

flex-direction

Determines the main axis — the direction items are laid out. Defaults to row (left → right).

row — left to right (default)  ·  row-reverse — right to left  ·  column — top to bottom  ·  column-reverse — bottom to top. Notice how swapping the direction also flips what "start" and "end" mean.

Lesson 3 of 8

justify-content

Controls how items are distributed along the main axis. This is the property you reach for when you want items centered, pushed to the ends, or spread out.

flex-start — pack items at the start  ·  flex-end — pack at the end  ·  center — center them  ·  space-between — equal gaps between items  ·  space-around — equal space around each item  ·  space-evenly — equal space everywhere including edges.

align-items

Controls alignment along the cross axis (perpendicular to main). Use this with justify-content to center things in both directions.

Items here have intentionally different heights so you can see alignment clearly. stretch (default) makes items fill the container height. baseline aligns items by their text baseline.

Lesson 5 of 8

flex-wrap

By default, flex items try to squeeze onto one line. flex-wrap: wrap lets them spill onto multiple lines when there isn't enough space.

Try nowrap first — notice the items shrink to fit. Then switch to wrap and they'll flow to new rows. wrap-reverse starts new rows above rather than below.

Lesson 6 of 8

flex-grow & flex-shrink

These item-level properties control how items share extra space (flex-grow) or give up space when there isn't enough (flex-shrink). The values are ratios, not pixel amounts.

If item A has flex-grow: 2 and item B has flex-grow: 1, item A gets twice as much of the extra space. A value of 0 means "don't grow at all." Drag the sliders below to see it live.

Lesson 7 of 8

Item Properties

Individual items can override container alignment and set their own sizing. Select an item, then adjust its properties.

align-self overrides align-items for just one item. order changes visual order without touching the HTML. flex-basis sets the starting size before growing/shrinking.

Flexbox Cheat Sheet

Everything you need at a glance. Bookmark this page.

Container — Main Axis

flex-direction
row · row-reverse · column · column-reverse
justify-content
flex-start · flex-end · center · space-between · space-around · space-evenly
flex-wrap
nowrap · wrap · wrap-reverse

Container — Cross Axis

align-items
stretch · flex-start · flex-end · center · baseline
align-content
Same values as justify-content (for multi-line)

Item Properties

flex-grow
0 (no grow) · 1 (equal share) · N (N× share)
flex-shrink
1 (default) · 0 (don't shrink)
flex-basis
auto · 0 · 200px · 30% …
flex
shorthand: grow shrink basis
align-self
Override align-items for one item
order
Integer. Default 0. Lower = earlier.

Common Recipes

Center everything
justify-content: center; align-items: center;
Space items out
justify-content: space-between;
Sidebar layout
sidebar: flex-shrink:0; main: flex-grow:1
Equal columns
each item: flex: 1;
